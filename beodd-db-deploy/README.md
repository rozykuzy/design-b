# beodd 디자인 소싱 DB — v3

아이폰 홈 화면 앱으로 쓰도록 전면 재작업한 버전입니다.

## v2에서 달라진 것

| | v2 | v3 |
|---|---|---|
| 스크롤 시 카테고리 | 위로 사라짐 | **항상 상단 고정** |
| 현재 위치 | 알 수 없음 | 해당 카테고리 칩이 자동 활성·중앙 정렬 |
| 앱 아이콘 | 임시 도형 | **beodd 로고** |
| 즐겨찾기 | 없음 | 별표 저장 (기기에 보관) |
| 정렬·표시 | 고정 | 기본순/이름순, 설명 켜기·끄기 |
| 다크 모드 | 없음 | iOS 설정 자동 반영 |
| 파일 크기 | 487KB | **142KB** (React 제거) |
| 첫 로딩 | 느림 | 1초 내외 |

## 파일 (전부 최상단, 폴더 없음)

```
index.html                  ← 앱 전체 (858곳 데이터 내장)
manifest.webmanifest        ← 홈 화면 앱 정보
sw.js                       ← 오프라인 캐시
beodd.otf                   ← beodd 서체 (워드마크·번호에만 사용)
PretendardVariable.woff2    ← 본문 서체
mark-96.png                 ← 헤더 로고
apple-touch-icon.png        ← 홈 화면 아이콘
icon-192.png / icon-512.png / icon-maskable-512.png / favicon-32.png
.nojekyll                   ← 숨김 파일, 반드시 포함
```

## 배포

기존 레포의 파일을 **전부 지우고** 위 파일을 올립니다.
(v2의 `assets/` 폴더가 남아 있으면 지워 주세요.)

GitHub → 레포 → Add file → Upload files → 전체 드래그 → Commit
`.nojekyll` 은 파인더에서 `Cmd + Shift + .` 로 표시됩니다.

배포 후 상단에 **858곳 · 15 카테고리** 가 보이면 정상입니다.

## 아이폰 설치 (직원 안내)

1. **사파리**로 주소 접속
2. 하단 공유 `□↑` → **홈 화면에 추가** → 추가
3. beodd 로고 아이콘으로 실행

이미 설치한 분은 앱을 완전히 종료 후 다시 열면 새 버전으로 갱신됩니다.

## 사용법

- **검색** — 브랜드명·작가명·지역·설명·도메인을 한 번에 찾습니다
- **카테고리 칩** — 상단에 항상 고정. 탭하면 해당 구역으로 이동
- **★** — 프로젝트별 후보를 모아둘 때. 칩의 `★ 즐겨찾기` 로 모아 보기
- **≡ 버튼** — 정렬(기본순/이름순), 설명 표시, 즐겨찾기 비우기
- **↑ 버튼** — 맨 위로
- 검색 결과는 주소에 남아 그대로 공유할 수 있습니다 (`?q=덴마크`)
- PC에서는 `/` 키로 검색창 이동

## 데이터 수정

`index.html` 안의 `window.__SOURCING_DB=[...]` 가 데이터입니다.
원본 엑셀을 고친 뒤 Claude에게 주면 새 `index.html` 을 만들어 줍니다.

**수정본 배포 시 `sw.js` 첫 줄 버전을 반드시 올리세요.**

```js
const VERSION = 'beodd-db-v3';   →   'beodd-db-v4';
```
