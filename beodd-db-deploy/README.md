## ⚠️ 배포 — 반드시 "완전히 지우고" 새로 올리기

지금까지 로고가 계속 이상하게 보인 원인은, **예전 버전 파일이 저장소에 남아있는 채로
새 파일만 추가**되었기 때문입니다. GitHub의 "Upload files"는 같은 이름 파일만 덮어쓰고,
새 패키지에 없는 옛날 파일(예전 로고 이미지 등)은 저장소에 계속 남습니다.

**그래서 이번엔 저장소 내용을 통째로 비우고 다시 올려야 합니다.**

1. GitHub 저장소 페이지 접속
2. 저장소 안의 **파일을 전부 선택 → 삭제(Delete files) → Commit**
   (또는 저장소를 삭제하고 같은 이름으로 새로 생성해도 됩니다)
3. 저장소가 완전히 빈 상태인지 확인
4. 이번 zip의 파일 전부(11개, `.nojekyll` 포함)를 새로 업로드 → Commit
5. Settings → Pages 에서 배포 상태 확인 (이미 켜져 있었다면 그대로 유지됨)

### 확인 방법

배포 후 사이트 접속 시:
- 상단 왼쪽에 **beodd 로고**(정사각형 흰 배경 없이, 배경색과 자연스럽게 어울리는 형태)
- **858곳 · 15 카테고리** 문구

가 보이면 정상입니다. 만약 여전히 **흰 사각형 안에 검은 b**가 보인다면, 예전 파일이
아직 저장소에 남아있는 것이니 2번 단계(파일 전체 삭제)를 다시 확인해 주세요.

아이폰에 이미 홈 화면 추가를 해두셨다면, 재배포 후 **앱을 완전히 종료(위로 스와이프)했다가
다시 열어야** 새 버전이 반영됩니다. 그래도 안 바뀌면 홈 화면 아이콘을 삭제하고 사파리에서
다시 접속해 새로 추가해 주세요.

## 사용법

- **검색창** — 브랜드·작가·지역·설명·도메인 동시 검색
- **카테고리 칩** — 상단 고정. 스크롤하면 현재 위치가 자동 표시
- **⌕** — 그 이름으로 웹 검색 (링크가 안 열릴 때)
- **★** — 프로젝트 후보 모아두기. 칩의 `★ 즐겨찾기` 로 모아 보기
- **≡** — 정렬(기본순/이름순), 설명 표시, 즐겨찾기 비우기
- 검색 결과는 주소에 남아 공유 가능 (`?q=덴마크`)
